Parallelizing the Sequential Agent Loop on Unified-Memory Personal Computers

Jerry Chen (chinjuic) and Ethan Chiu (ethanchi)
15-418/618 final project, Fall 2026, Carnegie Mellon University

Project proposal (PDF)

Summary

We will parallelize the sequential loop of a coding agent (LLM generation → tool execution → LLM generation → ⋯) on two unified-memory machines, an NVIDIA GB10 (DGX Spark) and an Apple M5 Pro laptop, replaying real agent traces on llama.cpp with real tools (e.g. ripgrep, a compiler, pytest, pandas). We work at two levels: (1) within one agent, we overlap CPU-side tool execution with GPU-side generation through pipelining and speculation in both directions, though a preliminary estimate suggests this gain may be limited; (2) across agents, we run several independent agent sessions on one machine with a shared, batched decode stream and concurrent tools. We ask how much parallelization gains on a machine where extra work shares memory bandwidth and capacity with the critical path, and how much a scheduler gains when it knows each tool's and agent's workload.
