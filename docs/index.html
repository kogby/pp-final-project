Scheduling Concurrent Coding Agents on Unified-Memory Hardware

Jerry Chen (chinjuic) and Ethan Chiu (ethanchi)
15-418/618 final project, Fall 2026, Carnegie Mellon University

Summary

We will parallelize the sequential loop of a coding agent (LLM generation → tool execution → ⋯) on two unified-memory machines (NVIDIA DGX Spark & M5 Mackbook Pro). We work at two levels: (1) within one agent, we overlap CPU-side tool execution with GPU-side generation through pipelining and through speculation on the next tool call or its result; (2) across agents, we run several independent agent sessions on one machine with a shared, batched decode stream and concurrent tools. We expect most of the benefit coming from the second level with an estimation from public traces. We plan to replay real agent traces on llama.cpp and run tool calls as real programs (e.g., pytest, pandas). Our central questions are (1) how much parallelization gains on a machine where the extra work shares memory bandwidth and capacity with the critical path, and (2) how much a scheduler gains when it knows each tool's and agent's workload.
